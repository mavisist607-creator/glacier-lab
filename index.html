地形雕刻工具

選擇工具後，在地形上按住拖曳。相機操作請切換「觀察」。

方塊式地形編輯

設定 X / Z 位置、Y 高度與方塊邊長，將局部地面加高到指定高度，或削減高度。

提示：方塊工具改變的是地形高度場，所有地面仍是連續、實心的立體山體。

冰河動態模擬

冰層從高海拔累積、向低處流動，並隨時間緩慢侵蝕底部岩盤。

讀懂冰河作用
冰河前進不等於冰塊直接往畫面前方移動；本模型以相鄰網格的冰面高度差計算流動方向。侵蝕與堆積採教學化近似。
觀察任務

試著用「侵蝕」工具拓寬山谷底部，再前往冰河模擬頁籤啟動冰流，觀察谷地如何改變。

操作說明

這是一個參考《冰河雕刻師》教學精神設計的獨立 3D 地形遊戲原型。

  1. 觀察：滑鼠左鍵旋轉、右鍵平移、滾輪縮放；觸控單指旋轉、雙指縮放與平移。
  2. 雕刻：選「抬升／侵蝕／平滑」，按住地面拖曳。此時暫停鏡頭旋轉。
  3. 方塊：設定 X、Z、Y 及大小，按「堆積至 Y」或「侵蝕至 Y」，可用預覽框確認位置。
  4. 冰河：切換冰河模擬，設定降雪、融冰、流動與侵蝕，再開始或單步演變。
  5. 保存：可將地形存在此瀏覽器、匯出 JSON 或從 JSON 匯入。

「海拔」為模型單位，不是實際公尺；一步對應 100 模擬年，只是教學時間尺度。
